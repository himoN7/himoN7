## 👨‍💻 About Me

I work at the intersection of software engineering, interface design, and applied research. Coming from a background in Textile Engineering, I approach digital systems with an appreciation for structure, material, and human interaction.

- 💻 **Desktop:** Crafting modern, native Windows applications using **WinUI 3**, **XAML**, and **WPF**.
- 📱 **Cross-Platform:** Developing fluid, responsive mobile experiences with **.NET MAUI**.
- 🎨 **Design Engineering:** Bridging the gap between UI/UX design (Figma) and front-end execution.
- 🔬 **Research:** Exploring smart textiles, wearable tactile sensors, and local/Edge AI workflows.
